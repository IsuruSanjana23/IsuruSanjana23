### What I've Built

**🧾 Point of Sale & Inventory Management System**
`Next.js 16` `React 19` `TypeScript` `Prisma` `SQLite` `Zustand` `Vitest`
- Full-stack SPA with 6 role-based dashboards and a 22-model Prisma schema (products, warehouse inventory, split-payment sales, purchasing, loyalty)
- JWT-authenticated RBAC across 11 permission modules, HMAC-SHA256 licensing, camera barcode scanning and split payments
- 23 Vitest test suites covering API endpoints, React components, stores and utilities

**📈 CryptoAgent AI**
`Next.js` `TypeScript` `Socket.IO` `CCXT` `Prisma` `SQLite`
- AI-assisted cryptocurrency trading terminal with exchange integration through CCXT
- Real-time market updates over Socket.IO with database persistence
- Neural-network components for AI-assisted market analysis

**🏏 AI Cricket Analyzer**
`Python` `Pandas` `scikit-learn` `XGBoost` `Random Forest`
- Predicts player performance from historical cricket data and selects an optimal T20 playing XI
- End-to-end pipeline: data collection → preprocessing → feature engineering → training & evaluation → player ranking → team selection

**🛒 Royal Bathik Lanka: E-Commerce REST API**
`FastAPI` `PostgreSQL` `SQLAlchemy` `Alembic` `JWT`
- 15+ REST endpoints for a live e-commerce platform covering catalog, inventory and orders
- JWT auth with OTP reset and email verification; ACID-compliant transactions that remove checkout race conditions

**Also built:** CampusMate (Prolog expert system) · Price Scout (multi-store product scraper) · F1 / GP Tempo (OpenF1 API analysis)
